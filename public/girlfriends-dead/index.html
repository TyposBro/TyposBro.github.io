What am I looking at?

Every frame of this cartoon is drawn from scratch in JavaScript on a <canvas> — a rigged 2D character, hand-coded scenes, timed to the song’s real tempo.

No music files are hosted here. The song comes from YouTube; the animation is original work and its code is open source.
